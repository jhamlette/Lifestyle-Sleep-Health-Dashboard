# Lifestyle & Sleep Health Dashboard 
**Power BI Project | Jordan Hamlette**

An interactive analysis of sleep duration, quality, stress, physical activity, and BMI relationships.  
Dataset: Kaggle – Sleep Health and Lifestyle (unaltered)

---

### Key Features
- KPI cards for Sleep Duration, Quality, and Stress  
- Trend and correlation visuals  
- “How to Read” panel for viewer clarity  
- Data notes acknowledging BMI category differences  
- Professional format and brand styling
